# CV files

Drop your 4 CV versions in this folder as plain text or Markdown files.
The filename (without extension) becomes the CV's display name in reports,
so name them clearly, e.g.:

- `architecture_governance.md`
- `enterprise_architecture.md`
- `solution_architecture.md`
- `transformation.md`

The pipeline runs fine with zero or partial CVs present — scoring and CV
recommendations just degrade to "no CV on file" until all 4 exist.
